# Curso de JavaScript desde Cero 🟨

Repositorio de aprendizaje y práctica de JavaScript. Este proyecto contiene scripts y ejercicios diseñados para asimilar las bases del lenguaje, la manipulación de datos y la lógica de programación paso a paso.

## 🧠 Conceptos Trabajados

El código de este curso aborda de forma práctica los siguientes fundamentos de JavaScript:

* **Estructuras de control y flujo:** Condicionales (`if/else`), operadores ternarios y sentencias `switch`.
* **Bucles e iteraciones:** Diferencias y casos de uso prácticos entre `for` y métodos de arrays como `forEach`.
* **Estructuras de datos:** Creación y manipulación de Arrays y Objetos.
* **Técnicas avanzadas básicas:** Desestructuración de arrays, anidación de objetos y validación de propiedades (ej. `if (persona.email)`).
* **Gestión de tipos:** Conversión de cadenas de texto a números flotantes (parsing) y manejo de errores básicos.
